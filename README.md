# Selenium Automation Testing with Java

## 📌 About This Project

This repository contains my hands-on practice and implementation of Selenium WebDriver automation using Java.

I have implemented various automation testing concepts and frameworks to improve my knowledge of web application automation testing.

## 🛠️ Technologies Used

- Java
- Selenium WebDriver
- TestNG
- Maven
- WebDriverManager
- Extent Reports
- Log4j2
- Eclipse IDE

## 📚 Topics Covered

The following Selenium automation concepts have been implemented in this repository:

1. **Batch Testing** – Execute multiple test cases together.
2. **Cookies** – Handle browser cookies using Selenium.
3. **Cross-Browser Testing** – Execute test cases across different browsers.
4. **Data-Driven Testing** – Execute test cases using external test data.
5. **WebDriverManager** – Manage browser drivers automatically.
6. **Encode Password** – Handle encoded passwords in automation scripts.
7. **Extent Reports** – Generate detailed automation execution reports.
8. **Extent Reports with TestNG** – Integrate Extent Reports with TestNG.
9. **Headless Browser Testing** – Execute tests without opening the browser UI.
10. **Log4j2** – Implement logging in automation scripts.
11. **Page Object Model (POM)** – Maintain reusable and structured page classes.
12. **Properties File** – Manage configuration data using properties files.
13. **Retry Logic** – Automatically retry failed test cases.
14. **TestNG Reports** – Generate and analyze TestNG execution reports.

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project in Eclipse IDE.

3. Update Maven dependencies:


4. Run the required Java program or TestNG XML file.
